# Установка и обновления

[English](../en/installation.md) · **Русский** · [Документация](index.md)

## Требования

Obsidian 1.7.2 или новее и хранилище с Markdown-заметками. Для собранного плагина не нужны сервер, аккаунт или Node.js. Базовые проверки выполнены на macOS в Obsidian 1.14.4. Манифест разрешает мобильную установку, но физические iOS/Android и минимальная версия Obsidian еще не проверены.

## Где взять собранные файлы

Когда доступен [GitHub Release](https://github.com/andrey-torlopov/NotelineObsidian/releases), скачайте отдельные файлы `main.js`, `manifest.json` и `styles.css`. Архив GitHub **Source code** не содержит исключенный из Git результат сборки. Установка из каталога Community появится после подачи и принятия плагина.

Если релиза пока нет, воспользуйтесь [сборкой из исходников](development.md) или готовой сборкой от автора. Локальный ZIP для установки может содержать папку `noteline/` с тремя нужными файлами.

## Ручная установка

1. Начните с тестового хранилища. Откройте его каталог конфигурации: обычно `.obsidian`, либо заданный вами каталог.
2. Создайте внутри него `plugins/noteline/` и скопируйте файлы:

```text
.obsidian/
  plugins/
    noteline/
      main.js
      manifest.json
      styles.css
```

3. При необходимости перезагрузите Obsidian и включите Noteline в **Настройки → Сторонние плагины**. Включайте только код, которому доверяете.
4. В палитре команд выполните **Noteline: Открыть временную ось**.

Имя папки должно совпадать с `manifest.id`: `noteline`. Не создавайте второй вложенный каталог `noteline`. Не копируйте `node_modules` и весь репозиторий в папку плагина. На мобильном устройстве собранные файлы должны попасть в каталог конфигурации того же хранилища до включения плагина.

## Обновление

Сохраните копию хранилища и `plugins/noteline/data.json`. Выключите Noteline, замените `main.js`, `manifest.json` и `styles.css` вместе, сохраните `data.json`, затем включите плагин. Используйте файлы одной версии.

Не удаляйте `data.json` при обычном обновлении: там хранятся состав оси, подставленные даты и раскладка. Поврежденная или неподдерживаемая схема вызывает сообщение, а не молчаливый сброс. [Копирование и восстановление](data-and-security.md).

Удаление сохраненных данных плагина удаляет ось, а не заметки. Если после такого сброса снова добавить заметку без даты, она может получить новую подставленную дату.
