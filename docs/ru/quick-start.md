# Быстрый старт и управление

[English](../en/quick-start.md) · **Русский** · [Документация](index.md)

## Добавление и чтение

Откройте **Noteline: Открыть временную ось** в палитре команд или кнопкой боковой ленты. Нажмите **Добавить заметку**. Найдите имя файла или полный путь внутри хранилища. Поиск охватывает все хранилище; одинаковые имена различаются путем.

Дополнительные способы: **Добавить на временную ось** в контекстном меню Markdown-файла и **Noteline: Добавить активную заметку на ось** для активной заметки. Повторное добавление фокусирует существующую карточку.

Отсутствие даты или тегов не блокирует добавление. Заметка без даты получает сохраненную подставленную дату; заполненная, но неверная дата требует исправления. [Правила метаданных](dates-and-tags.md).

В свернутом виде показаны имя файла без `.md`, дата, теги и действия. Кнопка раскрытия открывает Markdown с внутренней прокруткой. Одна заметка остается одной карточкой, даже если внутри несколько заголовков.

Название открывает исходную заметку в отдельной вкладке. Редактируйте текст там: карточка служит для чтения, а флажки задач отключены. Распознанный начальный блок метаданных скрывается из тела карточки без изменения файла. Относительные ссылки и изображения используют путь исходной заметки.

## Управление

| Элемент | Действие |
| --- | --- |
| Вертикальная ручка | Перенос выше/ниже без изменения даты |
| **↑/↓** в карточке | Перемещение на доступный уровень, в том числе сенсорными кнопками |
| Клавиши **↑/↓** при фокусе на ручке | Клавиатурное перемещение |
| **Escape** при переносе за ручку | Отмена, пока фокус на ручке |
| **−/+** | Масштаб относительно центра временного окна |
| `Ctrl/Cmd` + колесо над полем | Масштаб относительно даты под указателем |
| **←/→** на панели | Сдвиг к более ранним или поздним датам |
| `Shift` + колесо или горизонтальная прокрутка trackpad | Сдвиг временного окна |
| Обычное колесо | Прокрутка уровней; над раскрытым текстом сначала прокручивается его тело |
| **Показать все** | Обзор дат по горизонтали; большие наборы уровней прокручиваются вертикально |
| **Сегодня** | Переход к текущему дню с сохранением длительности окна |
| **К дате** | Ввод `YYYY-MM-DD` или `YYYY-MM-DD HH:mm` |
| **Параметры даты** | Изменение имен свойств и приоритета |

Совпадающие и близкие даты разносятся по уровням без перекрытия. Предпочитаемый уровень сохраняется; фактический может меняться при масштабировании и раскрытии. Минимальное окно — один час, максимальное определяется выбранными датами и их обзорной раскладкой.

Кольца на тонкой временной оси обозначают даты заметок и следуют выбранному диапазону. Если нет даты или тегов, кольцо серое, а соединитель пунктирный, как и серая рамка карточки. Шкала остаётся видимой при вертикальной прокрутке карточек.

Pinch-to-zoom не реализован. На телефоне или планшете используйте кнопки; проверка физических устройств еще предстоит.

## Теги и удаление с оси

Нажмите **+** рядом с тегами либо **Действия с карточкой → Добавить тег**. Применение допустимого тега меняет исходную заметку, сохраняя ее дату. [Куда записывается тег](dates-and-tags.md).

**Действия с карточкой → Убрать с оси** удаляет только участие и раскладку. Заметка остается в хранилище.

На панели видно состояние сохранения. При ошибке повторите запись до закрытия; см. [диагностику](troubleshooting.md).
