# Быстрый старт и управление

[English](../en/quick-start.md) · **Русский** · [Документация](index.md)

## Открытие оси

Версия 0.3.0 использует независимые `.timeline`-файлы. Выполните **Noteline: Открыть временную ось** в палитре команд или кнопкой боковой ленты. Если осей ещё нет, создайте файл в предложенной форме. **Noteline: Создать временную ось** создаёт другой файл, **Noteline: Выбрать временную ось** выбирает существующий. Разные файлы можно держать в отдельных вкладках.

Список **Выбрать временную ось** на панели открывает другую ось. **Создать ось**, **Сохранить копию оси**, **Перечитать файл оси** и **Удалить ось** управляют текущим документом. Перечитывание и удаление требуют подтверждения; копия сохраняет ссылки на те же заметки. [Файлы осей](timeline-files.md).

## Добавление и чтение

Нажмите **Добавить заметку** во вкладке нужной оси. Найдите имя файла или полный путь внутри хранилища. Поиск охватывает всё хранилище; одинаковые имена различаются путём.

Дополнительные способы: **Добавить на временную ось** в контекстном меню Markdown-файла и **Noteline: Добавить активную заметку на ось** для активной заметки. Они позволяют выбрать ось назначения. Повторное добавление фокусирует существующую карточку именно в этой оси; другая ось может использовать ту же заметку независимо.

Отсутствие даты или тегов не блокирует добавление. Заметка без даты получает сохраненную подставленную дату; заполненная, но неверная дата требует исправления. [Правила метаданных](dates-and-tags.md).

В свернутом виде показаны имя файла без `.md`, дата, теги и действия. Кнопка раскрытия открывает Markdown с внутренней прокруткой. Одна заметка остается одной карточкой, даже если внутри несколько заголовков.

Название открывает исходную заметку в отдельной вкладке. Редактируйте текст там: карточка служит для чтения, а флажки задач отключены. Распознанный начальный блок метаданных скрывается из тела карточки без изменения файла. Относительные ссылки и изображения используют путь исходной заметки.

## Управление

| Элемент | Действие |
| --- | --- |
| **Ориентация оси** | Выбор **Горизонтальная** или **Вертикальная** |
| **Направление дат** | Выбор **От старых к новым** или **От новых к старым** |
| Ручка карточки | Перенос поперёк оси: вверх/вниз в горизонтальном режиме, вправо/влево в вертикальном; дата сохраняется |
| **Дальше от оси / Ближе к оси** | Перемещение на доступный уровень дальше от оси / ближе к ней, в том числе сенсорными кнопками |
| Клавиши **↑/→** или **↓/←** при фокусе на ручке | Увеличение или уменьшение поперечного уровня соответственно |
| **Escape** при переносе за ручку | Отмена, пока фокус на ручке |
| **−/+** | Масштаб относительно центра временного окна |
| `Ctrl/Cmd` + колесо над полем | Масштаб относительно даты под указателем вдоль активной оси; прокрутка колеса меняет масштаб в обоих режимах |
| **Сдвинуть в прошлое / Сдвинуть в будущее** | Переход к более ранним / поздним датам; смысл сохраняется при обратном направлении |
| `Shift` + колесо | Сдвиг временного окна в обоих режимах |
| Горизонтальный жест trackpad в горизонтальном режиме | Сдвиг временного окна |
| Обычное колесо | Прокрутка поперечных уровней: вертикально в горизонтальном режиме, горизонтально в вертикальном; над раскрытым текстом сначала прокручивается его тело |
| **Показать все** | Обзор дат вдоль активной оси; дополнительные уровни прокручиваются поперёк неё |
| **Сегодня** | Переход к текущему дню с сохранением длительности окна |
| **К дате** | Ввод поддержанного значения, например `2026-10-22`, `2026-10`, `2026`, `XIX` или `II BC` |
| **Параметры даты** | Изменение имён свойств и приоритета для текущего файла оси |

Порядок от старых к новым идёт слева направо в горизонтальном режиме и сверху вниз в вертикальном; обратный порядок меняет эти направления. Ориентация и направление сохраняются в текущем файле оси. Совпадающие и близкие даты разносятся по поперечным уровням без перекрытия. Предпочитаемый уровень сохраняется; фактический может меняться при масштабировании и раскрытии. Минимальное окно — один час, максимальное определяется выбранными датами и их обзорной раскладкой.

Кольца на тонкой временной оси обозначают даты заметок и следуют выбранному диапазону. Если нет даты или тегов, кольцо серое, а соединитель пунктирный, как и серая рамка карточки. Шкала остаётся видимой при прокрутке поперечных уровней. В вертикальном режиме для этих уровней используйте горизонтальную полосу прокрутки; обычная прокрутка над полем также двигает их горизонтально. На сенсорном устройстве перемещайтесь во времени кнопками панели.

Pinch-to-zoom не реализован. На телефоне или планшете используйте кнопки; физические iOS/Android и сенсорные жесты ещё не проверены.

## Теги и удаление с оси

Нажмите **+** рядом с тегами либо **Действия с карточкой → Добавить тег**. Применение допустимого тега меняет исходную заметку, сохраняя ее дату. [Куда записывается тег](dates-and-tags.md).

**Действия с карточкой → Убрать с оси** удаляет только участие и раскладку. Заметка остается в хранилище.

На панели видно состояние сохранения текущего файла. При ошибке ввода-вывода устраните причину и нажмите **Ошибка сохранения — нажмите для повтора**. При конфликте файла сохраните несохранённые изменения через **Сохранить копию оси**, затем используйте **Перечитать файл оси**, если нужна версия с диска. Подтверждённое перечитывание заменяет расположение в памяти. См. [диагностику](troubleshooting.md).
