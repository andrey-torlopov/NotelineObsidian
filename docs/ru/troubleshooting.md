# Диагностика и ограничения

[English](../en/troubleshooting.md) · **Русский** · [Документация](index.md)

| Симптом | Что проверить |
| --- | --- |
| Noteline не виден среди сторонних плагинов | Положите три собранных файла непосредственно в `plugins/noteline/`, проверьте `manifest.id`, перезапустите Obsidian и проверьте минимальную версию приложения. В архиве исходников нет `main.js`. |
| В списке нет осей | Создайте или синхронизируйте файл с расширением `.timeline` внутри этого хранилища. Проверьте выбранное хранилище и исключённые папки. Одни настройки плагина не содержат файловые оси. |
| Ось открылась только для чтения | Сохраните `.timeline`-файл. Проверьте JSON, версию схемы и обязательные поля по [контракту файла](timeline-files.md). Неподдерживаемые данные не сбрасываются молча. |
| Дата не принимается | Используйте [поддерживаемый формат](dates-and-tags.md). Проверьте первое непустое свойство по приоритету, синтаксис YAML и повторяющиеся начальные строки даты. Заполненное неверное значение не заменяется сегодняшней датой. |
| Серая рамка карточки | Прочитайте причину. Добавьте дату и/или теги в исходную заметку; подставленная дата не устраняет отсутствие исходных метаданных. |
| Дата в тексте игнорируется | Перенесите её в настроенное свойство или распознаваемый начальный блок метаданных. Noteline не ищет дату события по всему тексту. |
| Карточки сместились при масштабировании или раскрытии | Защита от пересечений меняет фактический поперечный уровень. Предпочтительный уровень сохраняется в этом файле; положение вдоль времени по-прежнему задаётся датой. |
| Колесо двигает карточки вбок в вертикальном режиме | Это прокрутка поперечных уровней. Для дат используйте **Сдвинуть в прошлое / Сдвинуть в будущее**, **К дате** либо `Shift` + колесо. |
| Заметка не найдена | Восстановите файл по старому пути либо нажмите **Выбрать другой файл** в списке проблем и укажите нужную заметку. |
| Тег не добавляется | Проверьте синтаксис тега, YAML, повторяющиеся строки тегов и статус сохранения. Если запись идёт в YAML открытого исходного редактора, используйте свойства Obsidian либо закройте этот редактор и повторите действие. |
| Ошибка сохранения | Проверьте право записи, свободное место и синхронизацию. Нажмите **Ошибка сохранения — нажмите для повтора**. Дождитесь **Сохранено**, прежде чем закрывать Obsidian. |
| **Конфликт файла** или файл изменён извне | Сохраните несохранённые изменения через **Сохранить копию оси**. Затем нажмите **Перечитать файл оси** и подтверждайте только если нужна актуальная версия с диска. Сохраните обе версии; слияния раскладок нет. |
| Заметки синхронизируются, а ось не появилась на iOS | Синхронизируйте `.timeline`-файл вместе с заметками и вложениями. Включите нестандартные типы файлов на каждом устройстве; см. [настройку desktop/iOS](data-and-security.md#несколько-устройств). |
| После обновления не видна старая ось | Найдите перенесённый `Noteline.timeline` либо свободное имя с номером. Сохраните `data.json`, включая прежние поля для восстановления и пути в `notelineFiles`. [Миграция](data-and-security.md#перенос-из-версий-с-одной-осью). |

Переименования заметок и папок отслеживаются, пока Noteline включён и доступен для записи. После переименования при выключенном плагине или заблокированном сохранении может потребоваться перепривязка. Удаление карточки не удаляет заметку.

## Совместимость и границы версии

В версии 0.3.0 доступны независимые `.timeline`-файлы, отдельные вкладки, горизонтальное/вертикальное отображение, оба направления времени и одна карточка на заметку внутри каждого файла. Интервалы, повторяющиеся события, изменение даты перетаскиванием, экспорт изображения, совместное слияние раскладок и масштабирование щипком не реализованы. Текст карточки предназначен для чтения; редактируйте исходную заметку в Obsidian.

Версия 0.3.0 прошла базовые проверки в Obsidian 1.14.4 на macOS: миграция, независимые файлы осей, действия с файлами, обе ориентации и направления, неполные даты и даты до нашей эры, сохранение раскладки и внешние изменения сохранённого файла. Манифест разрешает мобильную установку, код использует публичные API, совместимые с браузером. Физические iOS/Android, Windows/Linux, сама Obsidian 1.7.2, сенсорные жесты и фактический перенос/конфликты средств синхронизации ещё не проверены. Производительность на больших хранилищах не подтверждена. Успешное применение локального внешнего изменения не проверяет перенос и конфликты конкретного средства синхронизации.

## Сообщение об ошибке

Создайте [issue](https://github.com/andrey-torlopov/NotelineObsidian/issues) с версиями Noteline и Obsidian, ОС и устройством, шагами воспроизведения, ожидаемым поведением, ориентацией/направлением и текстом ошибки. Для проблем метаданных приложите минимальную обезличенную заметку, для проблем файла — [минимальный документ оси](timeline-files.md). Если доступны ошибки консоли, добавьте относящиеся к проблеме строки; доступ к консоли зависит от платформы.

Удалите личный текст, пути хранилища и посторонние данные плагинов перед публикацией. Укажите, были ли включены другие плагины и синхронизация. Не прикладывайте личное хранилище целиком.
