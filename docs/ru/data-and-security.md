# Данные, приватность, копирование и синхронизация

[English](../en/data-and-security.md) · **Русский** · [Документация](index.md)

## Что сохраняется

Заметки остаются Markdown-файлами по исходным путям хранилища. Noteline читает их содержимое и метаданные для карточек. Собственное состояние сохраняется через API данных плагина Obsidian, обычно в `.obsidian/plugins/noteline/data.json`. Если выбран другой каталог конфигурации хранилища, он заменяет `.obsidian` в этом пути.

Файл данных содержит версию схемы `1`, настройки свойств даты, выбранные пути заметок и ID записей, предпочтительные уровни по вертикали, состояния раскрытия, сохранённые подставленные даты и последнюю область просмотра. Дубликаты текстов заметок и вложений в нём не хранятся.

Добавление заметки, перемещение и раскрытие карточки, удаление карточки с оси меняют данные плагина. Они не переписывают и не удаляют заметку. **Явное добавление тега записывает его в исходный файл.** При записи YAML его форматирование может измениться; значения других свойств и тело сохраняются. [Правила записи тегов](dates-and-tags.md).

## Сеть и внешнее содержимое

Noteline не выполняет собственных сетевых запросов и не содержит телеметрии, учётной записи или подключения к серверу. Markdown отображает Obsidian. Изображения, встраивания, ссылки и другие плагины могут обращаться к внешним ресурсам; временная ось не фильтрует сетевое содержимое.

## Резервная копия и восстановление

1. Дождитесь статуса **Сохранено**. Сначала устраните ошибку сохранения, если она есть.
2. Закройте Obsidian на устройствах с этим хранилищем и приостановите синхронизацию перед копированием или восстановлением.
3. Скопируйте всё хранилище: заметки, вложения и скрытый каталог конфигурации с `plugins/noteline/data.json`.
4. Для восстановления сначала сохраните копию текущих файлов, восстановите соответствующие друг другу заметки и данные плагина, затем откройте Obsidian. Проверьте пути, состав оси, подставленные даты и расположение карточек.

Noteline не создаёт автоматических резервных копий. Один `data.json` не восстановит удалённые заметки. Одни заметки не восстановят состав и расположение оси.

Удаление `data.json` сбрасывает ось и настройки. Сохранённые подставленные даты также пропадают, поэтому повторно добавленная заметка без даты может оказаться на другом дне. Это не штатный способ исправления ошибок.

## Несколько устройств

Перенос файлов выполняет ваше средство синхронизации. Проверьте, что оно включает данные плагина: синхронизация установки и настроек зависит от выбранного инструмента. Меняйте ось на одном устройстве за раз и дожидайтесь окончания синхронизации перед переходом на другое.

Внешнее изменение можно перечитать, когда локальные данные сохранены. Если оно приходит во время записи или при несохранённых изменениях, появляется **Конфликт настроек**, дальнейшие изменения блокируются. Два расположения автоматически не объединяются. Сохраните обе копии, остановите второе устройство, при закрытом Obsidian выберите сохраняемый файл данных и перезагрузите плагин. При перезагрузке несохранённые изменения в памяти могут пропасть; при необходимости сначала вручную зафиксируйте расположение карточек.

Повреждённая или неподдерживаемая схема включает режим чтения, исходный файл не перезаписывается. Сохраните его и восстановите исправную копию либо используйте совместимую версию плагина. [Диагностика](troubleshooting.md).
