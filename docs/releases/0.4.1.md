# Noteline 0.4.1

Card dates now use the canonical source value for display. The full calendar coordinate remains available for sorting and placement, but cannot supply extra components to a card label.

| Note value | Card label |
| --- | --- |
| `2026-10-23` | `2026-10-23` |
| `2026-10` | `2026-10` |
| `2026` | `2026` |
| `2026-10-23 00:00` | `2026-10-23 00:00` |
| `2026-10-01` | `2026-10-01` |

Roman centuries and BCE labels retain their existing notation. A missing date still uses the saved day of insertion. Note contents, timeline coordinates, scale labels, touch controls, and the `.timeline` schema are unchanged.

**Verification:** metadata and actual card-update regressions, the complete automated suite, lint, typecheck, manifest validation, and production build. The original device report was not reproduced in the existing source path; this update hardens the display contract against lost precision. Confirmation in the user's Obsidian installation is still needed. If the Markdown itself already contains a full timestamp, its explicit time remains visible. [Date rules](../en/dates-and-tags.md).

**Update:** replace `main.js`, `manifest.json`, and `styles.css` together and reload the plugin. Requires Obsidian 1.7.2+; ID remains `noteline`. For rollback, reinstall the three release assets from 0.4.0; no new migration is involved.

Дата карточки теперь выводится из исходного нормализованного значения. Полная календарная координата используется для сортировки и размещения, но не может дописать лишние компоненты в подпись карточки.

| Значение в заметке | Подпись карточки |
| --- | --- |
| `2026-10-23` | `2026-10-23` |
| `2026-10` | `2026-10` |
| `2026` | `2026` |
| `2026-10-23 00:00` | `2026-10-23 00:00` |
| `2026-10-01` | `2026-10-01` |

Римские века и обозначения до нашей эры сохраняют прежний формат. При отсутствии даты используется сохранённый день добавления. Текст заметок, координаты, подписи шкалы, сенсорное управление и схема `.timeline` не меняются.

**Проверка:** регрессии метаданных и настоящего метода обновления карточки, полный набор автоматических тестов, lint, типы, манифесты и production-сборка. Исходное поведение с устройства не воспроизведено на существующем пути исходников; выпуск усиливает гарантию вывода при потере точности. Результат ещё нужно подтвердить в установленном Obsidian пользователя. Если сам Markdown уже содержит полный timestamp, явно указанное время сохраняется. [Правила дат](../ru/dates-and-tags.md).

**Обновление:** замените `main.js`, `manifest.json` и `styles.css` вместе, затем перезагрузите плагин. Требуется Obsidian 1.7.2+, ID остаётся `noteline`. Для отката переустановите три файла выпуска 0.4.0; новой миграции нет.
