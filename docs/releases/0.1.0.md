# Noteline 0.1.0

Noteline places existing vault notes on a horizontal timeline with expandable Markdown cards.

- Read event dates from configurable properties or a leading `📅` line.
- Add undated notes using a saved local date of addition. Gray frames and text explain missing dates or tags.
- Arrange cards vertically, zoom, pan, fit the selected dates, and jump to today or a date.
- Add tags explicitly to the source note. Moving or removing a card does not rewrite or delete the note.
- Preserve membership, fallback dates, layout, and view state between sessions.
- Includes [English](https://github.com/andrey-torlopov/NotelineObsidian/blob/0.1.0/docs/en/index.md) and [Russian](https://github.com/andrey-torlopov/NotelineObsidian/blob/0.1.0/docs/ru/index.md) documentation. The plugin interface is Russian.

**Installation:** download the individual `main.js`, `manifest.json`, and `styles.css` assets into your vault's `.obsidian/plugins/noteline/` folder, then enable Noteline in Community plugins. A custom configuration folder replaces `.obsidian`. GitHub's source-code archives do not include the compiled plugin. Community directory acceptance is a separate process.

Requires Obsidian **1.7.2+**. Desktop smoke checks were performed on macOS with Obsidian **1.14.4**. The manifest permits mobile installation; physical iOS/Android, Windows/Linux, and the minimum declared app version remain unverified. Use a test vault first and back up notes and plugin `data.json` before updating. Concurrent timeline edits are not merged automatically.

Noteline размещает существующие заметки хранилища на горизонтальной оси с раскрываемыми Markdown-карточками.

- Даты из настраиваемых свойств или начальной строки `📅`.
- Для заметки без даты сохраняется локальная дата добавления. Серый контур и текст показывают отсутствие даты или тегов.
- Вертикальная раскладка, масштабирование, сдвиг, обзор выбранных дат и переход к дате или сегодняшнему дню.
- Явное добавление тегов в исходную заметку. Перемещение и удаление карточки с оси не переписывают и не удаляют заметку.
- Сохранение состава оси, подставленных дат, раскладки и области просмотра между сеансами.
- Документация на русском и английском; интерфейс плагина русский.

**Установка:** скачайте отдельные файлы `main.js`, `manifest.json` и `styles.css` в `.obsidian/plugins/noteline/` вашего хранилища и включите Noteline среди сторонних плагинов. При своей конфигурационной папке замените `.obsidian` на неё. Архивы исходников GitHub не содержат собранный плагин. Принятие в каталог Community выполняется отдельно.

Требуется Obsidian **1.7.2+**. Базовая нативная проверка выполнена на macOS с Obsidian **1.14.4**. Манифест разрешает мобильную установку; физические iOS/Android, Windows/Linux и минимальная заявленная версия приложения ещё не проверены. Начните с тестового хранилища. Перед обновлением сохраните заметки и `data.json` плагина. Одновременные изменения оси автоматически не объединяются.
