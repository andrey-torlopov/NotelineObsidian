# Noteline banner artwork / Иллюстрация Noteline

[English README](../README.md) · [Русский README](../README-ru.md)

The files [`banner.svg`](banner.svg) and [`banner.png`](banner.png) are original geometric artwork created for Noteline. They contain no copied images, third-party logos, or embedded font files. The image illustrates a timeline concept; it is not a screenshot or a promise of a particular interface language.

You may copy, modify, and distribute them without attribution. This dedication covers the original artwork; it grants no trademark rights. The plugin code and documentation use the repository's [MIT license](../LICENSE).

The editable SVG uses ordinary text with an Arial/sans-serif fallback. The PNG is rendered at **1920 × 480** pixels. Keep the viewBox and aspect ratio when exporting a replacement PNG. A different installed font may change text metrics; inspect the result before committing it.
