# Noteline documentation

**English** · [Русский](../ru/index.md) · [README](../../README.md)

Guides for version 0.4.0: install a built plugin, create independent `.timeline` files, place existing notes in time, and preserve the files across devices. Different timelines can stay open in separate tabs, with their own note selection, date settings, layout, orientation, and direction.

Teachers can arrange lesson topics and course milestones; developers can follow releases, incidents, and development logs; managers can track project milestones and decisions; historians can place archival notes and events by year or century, including BCE. Represent each milestone, event, or log entry with a dated note and select it for the relevant timeline.

The interface is currently Russian. These pages translate the instructions and retain actual Russian labels where you need to find a control. Note contents and property names are never translated.

Start with the timeline creation/selection commands or open a `.timeline` file. Its toolbar provides note addition, timeline selection, creation, deletion, saving a copy, and reloading, plus horizontal/vertical orientation and chronological direction. Sync timeline files together with their notes; synchronizing only plugin settings does not carry the timeline. Native 0.3.0 smoke checks passed on macOS with Obsidian 1.14.4. See [remaining platform, gesture, minimum-version, and sync verification limits](troubleshooting.md#compatibility-and-scope).
